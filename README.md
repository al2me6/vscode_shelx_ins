# VSCode SHELX Instructions Syntax Support

Syntax highlighting for the [SHELX](https://shelx.uni-goettingen.de/) instruction file format used in single-crystal X-ray crystallography.

![sample syntax-highlighted `.ins` file](img/cyclo.png)

(Sample data taken from example `cyclo` in Müller, P.; Herbst-Irmer, R.; Spek, A. L.; Schneider, T. R.; Sawaya, M. R. Crystal Structure Refinement; Oxford University Press, 2006. https://doi.org/10.1093/acprof:oso/9780198570769.001.0001.)
